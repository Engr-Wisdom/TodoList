# Overview
 
Taskora is a simple and intuitive task management application designed to help users organize and manage their responsibilities without the complexity of larger project-management platforms.
 
Users can create, view, update, and delete tasks. Each task includes:
 
- A title
- A summary
- A category: Work, Home/Chores, Church Calling, or School
- A due date
- A priority level from 1–10, with 10 being the highest priority
- A completion status
 
The application also allows users to search for tasks and filter them by category, due date, priority, and completion status. Overdue tasks are highlighted to make them easier to identify.
 
Our goal is to provide the essential tools needed to manage tasks efficiently without overwhelming users with unnecessary or complicated features.
